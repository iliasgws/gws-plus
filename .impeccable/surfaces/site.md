# Surface brief — site/

Scope: whole static website (landing first, curated docs behind). Mode: **Persuade** (with a Read-grade docs section).
Audience: parents of Greenwood School pupils, French-speaking, mostly on a phone; documentation readers second.
Job: understand what Greenwood School + does and install it.
Action: download the APK from GitHub Releases.
Proof: existing facts only — feature set, verified/unverified status, live release versions, the app icon. No screenshots exist in the repository and none may be fabricated.
Constraints: the « Le registre » world is fixed (the app's `docs/product/DESIGN.md` is untouched); the custom icon is chrome only (header logo + favicon set); publish the curated 11-file public docs set; French with correct accents; code-led build (no image generation this session); every file of this work lives under `site/`; no app code changes.

Chosen direction: **Registre d'appel** (attendance roll) — the dealt lead of seed `9b524b63`.
Memorable moment: the signature line — the download action drawn as the sheet's red-pen signature at the foot of the roll.

## Direction contract

THESIS: The site is the school's attendance roll: every capability of the app called by name and given its true mark — it refuses the category-default hero-with-screenshots landing that promises instead of proving.

OWN-WORLD: « Le registre »: paper ground, ink text, sage margin annotations, one red pen reserved for the required action. Ruled rows, margin marks (✓ / ⚠) and filed pages are the component language; recognizable with every word removed. The app icon appears only as header logo and favicon.

STORY: A parent reads the roll, sees each function with its honest state, believes the app is real and maintained, signs it (downloads the APK), then consults the filed documentation.

FIRST VIEWPORT: A full-width ruled sheet: « Greenwood School + » title with a date line at the top; six function rows (Registre, Actualités, Emploi du temps, Devoirs, Documents, Messagerie/Demandes) each with a parent-voice benefit line and a ✓/⚠ mark in the margin, filling the body at legible row height; the red-pen signature line — primary download action — sits at the sheet's foot above the fold; docs are one scroll below, filed as annotated pages.

FORM: Registre d'appel, position 1 on the ranked list (dealt lead, index 7 of 7 grounded structures); seed key 9b524b63.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
